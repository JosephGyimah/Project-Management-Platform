# Project Management Platform

TypeScript monorepo starter for a React, Node, and PostgreSQL project management app.

## Run locally

```sh
npm install
copy .env.example .env
npm run db:up
npm run dev
```

- Web: http://localhost:5173
- API: http://localhost:4000/health

See [ARCHITECTURE.md](ARCHITECTURE.md) for the domain model, API contract, repository workflow, and delivery sequence.
